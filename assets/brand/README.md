# Agent OZE Brand Assets

Canonical brand assets for Agent OZE live in this directory.

## Files

- `agent-oze-icon.png` / `agent-oze-icon.svg` — square mark for Stripe icon, avatars, favicons, thumbnails, watermarks, and compact content placements.
- `agent-oze-logo.png` / `agent-oze-logo.svg` — horizontal logo for Stripe logo, decks, content end cards, brand bars, and larger placements.

## Rules

- Use these files as the source of truth. Do not regenerate, redraw, or invent alternate Agent OZE logos.
- `deliverables/stripe-branding/` is an export folder, not the source of truth.
- If an image model cannot accept a reference image, describe the mark exactly: a bright `#3DFF7A` glowing ring with a centered `#3DFF7A` dot on a near-black `#050607` / `#0b0d10` background.
- Keep the brand palette tight: near-black background, `#3DFF7A` accent, white/off-white text.
